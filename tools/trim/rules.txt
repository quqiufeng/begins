# 驱动裁剪规则：按「定义该 CONFIG 的 Kconfig 文件所在目录」前缀匹配
# 语法: KILL <目录前缀>   KEEP <CONFIG 符号>
# 本机: AMD Matisse(Ryzen) + NVMe + AMD SATA + RTL8168 + RTX3080(nvidia 外部模块) + USB xHCI
# 锚点: nvidia.contract 需要 drm_kms_helper(27) / acpi_video(2) / drm_client_lib(1) / drm_ttm_helper(1)
